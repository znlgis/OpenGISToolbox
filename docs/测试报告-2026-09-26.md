## 四、缺陷清单与修复

### 4.1 应用层（本仓库，已修复并由回归覆盖）

| # | 缺陷（`CsvToVectorTool`） | 根因 | 修复 |
|---|--------------------------|------|------|
| 1 | Tab 分隔符静默回退为逗号 | `GetOptional` 的 `IsNullOrWhiteSpace` 把 Tab 字符当作"未填" | 直接读取参数 + `ResolveDelimiter` 规范化（兼容实际 Tab 与字面 `\t`） |
| 2 | 引号字段被拆坏（`"北京, 中国"` → 两列） | `Split(delimiter)` 无 RFC 4180 语义 | 新增逐字符解析器：引号包裹、`""` 转义、字段内换行、CRLF/LF/空行 |
| 3 | GBK 文件读出乱码 | 固定按 UTF-8 读取 | 经引擎 `EncodingUtil` 探测（BOM → 严格 UTF-8 → GBK/ANSI 回退） |
| 4 | 重复表头时坐标列取到最后一列，全行被跳过 | 匹配循环被后者覆盖 | 首次匹配优先；同名列按普通属性保留 |

### 4.2 引擎层（`opengis-utils-for-net`）

**（a）通过升级依赖解除（1.0.8 → 1.1.0）**

- **含 DATE/DATETIME 字段的图层转 KML 整层失败**（GDAL 3.13 原生 KML writer 对 `OFTDate` 列逐要素 `CreateFeature` 失败）。引擎 1.1.0 将 KML 日期列降级为 ISO 文本后，转换成功（`BoundaryFieldTests` 阳性覆盖）。
- 同版本另含：空几何跳过、DXF 固定 schema 字段索引、PostgreSQL MULTI 升维等引擎修复，升级后全量回归通过。

**（b）本轮新发现并已在引擎仓库修复（提交 `928edeb`，待发版后升级解除）**

| 缺陷 | 修复 |
|------|------|
| **KML 属性值整体错位 2 位**（驱动预置 `Name`/`Description` 内建字段；`featurecla` 收到 `LABELRANK` 的值） | 字段索引映射叠加创建前基偏移；源 `Name` 不再输出重复 `<name>` |
| **零基 FID 链式相撞**（GPKG/OpenFileGDB 下 `Fid=0` 触发的 UNIQUE 冲突与 FID 整体偏移） | GPKG 保留 `fid=0`；OpenFileGDB 将 `Fid=0` 延迟至末尾（`max+1` 自动分配） |
| **PostgreSQL DOUBLE/FLOAT 宽度溢出**（DBF 派生 `numeric(24,15)`，`10^9` 级人口值 COPY 溢出） | PG 下跳过宽度/精度，建无约束列 |
| **复合几何顶点数为 0**（MULTI\* 在 OGR 基类 `GetPointCount` 返回 0） | `GeometryUtil.NumPoints` 递归子几何累加 |

引擎侧验证：271 xunit + 边界/NE 真实数据 harness 全绿（0 Fail）。
